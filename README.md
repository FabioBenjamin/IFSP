## :memo: Sobre o Repositório
Este repositório foi estruturado para centralizar, versionar e organizar todo o meu percurso acadêmico e técnico no **IFSP**. Ele reúne códigos, listas de exercícios, laboratórios e projetos práticos desenvolvidos desde o **1º, 2º e 3º ano**, servindo como base sólida e histórico evolutivo para os desafios e projetos do **4º ano**.

O intuito é manter um código limpo, documentado e de fácil consulta, refletindo o aprendizado contínuo nas disciplinas técnicas e fundamentais do curso.

---

## :books: Estrutura do Repositório por Matérias e Tecnologias

O projeto está dividido nas seguintes pastas principais:

### 🗃️ Banco-De-Dados
* Modelagem de dados (Conceitual e Lógica);
* Criação de tabelas, relacionamentos e chaves estrangeiras;
* Consultas SQL avançadas, procedimentos e regras de negócio via SGBD (MySQL / Workbench).

### 🌐 HTML
* Estruturação de páginas web semânticas;
* Formulários, tabelas e organização de layouts;
* Fundamentos de estilização e boas práticas de marcação.

### ☕ Java
* Fundamentos de lógica e algoritmos;
* Programação Orientada a Objetos (POO): Classes, Objetos, Herança, Polimorfismo e Encapsulamento;
* Desenvolvimento de estruturas de dados e sistemas de console/desktop.

### 💻 Javascript
* Manipulação do DOM e interatividade de páginas web;
* Lógica de programação voltada para o ambiente web;
* Validações de formulários e consumo básico de dados dinâmicos.

### 🐍 Python
* Algoritmos estruturados e resolução de problemas matemáticos/lógicos;
* Automação de tarefas e manipulação de arquivos;
* Base para integração com frameworks back-end.

## 📅 Linha do Tempo da Jornada no IFSP

* **1º Ano:** Construção da base lógica, introdução aos fundamentos de programação (Python/Java) e primeiras experiências com desenvolvimento web (HTML).
* **2º Ano:** Aprofundamento em Programação Orientada a Objetos (Java), introdução a estruturas de dados e modelagem inicial de Banco de Dados.
* **3º Ano:** Consolidação de conceitos avançados, manipulação avançada de banco de dados, interatividade com JavaScript e desenvolvimento de aplicações mais complexas.
* **4º Ano (Atual):** Reta final focada no aprimoramento técnico avançado, projetos integradores robustos, TCC (Trabalho de Conclusão de Curso) e preparação para o mercado de trabalho.
